# Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/niro4-1/cli-tool.git
   cd cli-tool
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the tool:**
   ```bash
   npm start
   ```

4. **For more options, check the documentation.**
